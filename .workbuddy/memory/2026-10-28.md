## 踩坑：GCM 缓存旧凭据导致 403

现象：`git push` 报 `remote: Permission to honhwa/plugin-ssms.git denied to honhwa.` 403，即使提供有 `repo` scope 的 PAT。

原因：全局 `credential.helper=manager`（Git Credential Manager）优先返回了缓存的只读/过期 token，命令行 `-c credential.helper='!f...'` 只是追加，未覆盖 GCM。

解决：先清空 helper 列表再注入 PAT：

```
git -c credential.helper= \
    -c credential.helper='!f() { echo username=x-access-token; echo "password=$GH_PAT"; }; f' \
    push -u origin <branch>
```

要点：`credential.helper=`（空值）必须先出现，重置多值配置链；token 不落盘进 `.git/config`。

## 后续：GCM OAuth 登录不可用 → 改存 PAT
